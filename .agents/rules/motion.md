# Motion and interaction standard

Always on, for every UI change: library components, demos and the site. The owner set these patterns while building the site (2026-10-12 to 2026-10-14). New work uses them without being asked. The full token spec is in `docs-internal/01-brand/design-system.md` §9.

## Principles
- **Motion explains a change.** It shows where something went, what opened, or what's active now. Nothing moves just to decorate: no hover tilts, bounces or wiggles (the owner removed a hover tilt on 2026-10-14).
- **Content comes and goes through the blur, not a plain fade** (owner, 2026-10-15). Anything that appears, leaves or swaps sharpens in from a 6px blur as it fades, with the movement its pattern already has: popovers, tooltips, dialogs, tab panels, list items, messages, swapped labels and icons. Use `blur` / `swap` from `@fewtone/ui/lib/motion`, or the CSS `animate-blur-in` / `animate-blur-out`, `rise-in`, `scale-in` and `popover-in` / `popover-out`. ADR 0011.
  - **Still a plain fade:** full-screen overlays, fills and highlights (Checkbox fill, Switch colour, Toggle Group pill, row highlights), hover states and scroll-edge fades. A blurred solid shape reads as a glow.
  - **Reduced motion:** opacity only, no blur. Where a component doesn't branch on it, use `blur.shown` as the hidden value.
  - **Clean up:** an imperative `animate()` clears `filter` when it finishes, so no stacking context is left behind.
- **Only `transform` and `opacity` move.** The exceptions:
  - height, through the height pattern below
  - a tiny icon stroke drawing itself in (`pathLength`, for example Loading Button's check)
  - the blur on content that comes and goes (above)
- **Use the presets:**
  - springs: `spring.snappy` (small controls), `spring.smooth` (panels), `spring.bouncy` (rare delight)
  - the blur: `blur.hidden` / `blur.shown`, and `swap` for content swapping in place
  - durations and easings: `duration.*` and `ease.*` from `@fewtone/ui/lib/motion`, and `duration-(--duration-*)` / `ease-*` in CSS
  - never invent numbers
- **Reduced motion, always.** CSS durations collapse automatically. JavaScript animations check `useReducedMotion()` and use `{ duration: 0 }`, or opacity only.
- **Nothing animates on first paint.** Use `initial={false}`. A state the user didn't just change, such as a choice restored from storage, jumps instead of gliding.
- **One indicator per instance.** Scope shared-layout animations with `LayoutGroup id={useId()}` (library) or `PillGroup` (site), so two sets on a page never trade an indicator.
- **Clean up.** Cancel Web Animations when they finish, remove injected styles, and disconnect observers. A forwards-filling animation left behind breaks the next one.
- **Cost.** Prefer GPU-only (transform, opacity) over clip-path, and clip-path over mask, filter or blur. The 6px blur on content that comes and goes is the standard (motion runs filter on the compositor); never animate a full-screen blur.

## Which pattern to use
| Situation | Pattern | Reuse |
|---|---|---|
| Active item in a horizontal set: tabs, segmented control, filter | A pill or underline that **slides** to the active item (`layoutId`, `spring.snappy`). The item is `relative`, the set `isolate`. | Site: `Pill` and `PillGroup` (`apps/www/components/motion/pill.tsx`); `SlidingTabList` for Radix Tabs (`components/docs/sliding-tab-list.tsx`). Library: Switcher and Tabs (`layoutId` inside `LayoutGroup id={useId()}`, with the corner radius read from the option) |
| Active or hovered row in a vertical list: sidebar, menu, results, listbox | **One** highlight that glides between rows (transform only, works in scroll containers). Hover highlights are mouse-only and fade out on leave. It jumps (`instant`) while typing changes the list. | Site: `RowIndicator` + `useRowBox` (`components/motion/row-indicator.tsx`). Library: a `layoutId` pill inside the focused item, with `layoutScroll` on the scroller (Select); Dropdown and Context Menu share one across a menu and its sub-menus; Navigation Menu has one per panel for its links |
| Levels of a trail that change (breadcrumb after a page change) | A new level **grows out of the one before it**: it slides 8px out from the left through the blur (`duration.slow`, `ease.out`), the separator first and the name `duration.instant` later, so the trail draws itself. A level you leave slides back in (`duration.fast`, `ease.in`); the rest glide to their places (`layout="position"`, `spring.snappy`); the level you were on dims to a link on the same timing (its colour lives on the level). `AnimatePresence initial={false}` round the levels, keyed by their path, so a static trail never moves. Content that changes with it moves the way you went: forward comes in from the right, back from the left, 12px, the rows staggered by 0.05s, old and new overlapping (`popLayout`). | Breadcrumb and its folder example |
| Content that changes height: tab panels, an opening section, accordion | The wrapper **glides** to the new height, never on a spring that overshoots, because overshoot bounces the page: an eased tween (`duration.slow`, `ease.out`), or `spring.smooth`, which is damped enough to land without a visible overshoot (about 0.1%) and turns round mid-glide keeping its speed. Clip only while moving. Instant with reduced motion. | Site: `AutoHeight` (`components/motion/auto-height.tsx`). Library, a section that opens and closes in place: **Accordion** runs on motion (owner, 2026-10-19: "more smoother"). Radix's `forceMount` keeps the content in the page (`hidden="until-found"` while closed, so find in page opens it). The height glides on `spring.smooth` both ways, and the content is staged against it: opening, it follows `duration.instant` later, sharpening through the blur as it settles 6px down (`duration.slow`, `ease.out`); closing, it leaves first (`duration.fast`, `ease.in`), then the empty box folds. Simpler parts can use Radix's measured height with the shipped `animate-collapsible-open` / `-close` keyframes, the content coming through the blur (Sidebar's groups). Spacing that changes with the height glides with it (Accordion's separated sections move 4px further apart while open: a margin transition on `duration-slow` + `ease-out`). JavaScript measure-and-tween is for content Radix doesn't measure (Tabs' panels) |
| Long section | Show a fixed height with a fade and "View all …". Once open, a sticky "View less" floats at the bottom of the screen with a shadow and lands at the section's end. Pressing it folds the section while gliding back to the heading, and focus returns. Hidden items rise 12px through the blur, staggered by 0.05s; the buttons come and go through it too. | `Expandable` (`components/docs/expandable.tsx`) |
| Popover, select, menu, tooltip | CSS keyframes `animate-popover-in` / `animate-popover-out`: scaling from `--radix-*-transform-origin` through the blur. A simple tooltip can use `animate-blur-in`. | Select |
| Dialog, drawer, sheet | Radix Dialog with `forceMount` inside `AnimatePresence`. It enters on `spring.snappy` and exits on a timed `duration.base` + `ease.in`, so the page never feels stuck. A window comes through the blur, scaling from its trigger's centre (it grows out of the button that opened it); a drawer slides; the overlay only fades. While it leaves, clicks pass through, and focus returns to the trigger only if it went away with the window. | Library: Dialog (Alert Dialog reuses it), Sheet. Site: `mobile-nav.tsx`, `command-menu.tsx` |
| A choice's mark moving between separate controls (radio dots) | At rest each control shows its own mark. On a change, **one shared mark travels** from the old control's centre to the new one's, then hands back to the new control's own mark in the same frame. Centres come from offsets (layout pixels), not on-screen boxes, so zoom doesn't double the trip. Slide on `spring.snappy`, or stretch (the front leaves first, the back follows `duration.instant` later, landing round). Mid-trip, a new choice leaves from where the mark is. | Radio Group (`travel`) |
| A control's knob or thumb moving between ends | Place it with numbers, not by measuring: `x` and its own width, on `spring.snappy`. **Hover:** the thumb stays at its end and stretches 2px towards the other side; it never shifts, and doesn't stretch straight after a change. **Press:** it stretches further. **A change:** it stays stretched for the trip, then settles round at the far end. **The "on" colour follows the thumb:** a pill under it, driven only by the thumb's live position (motion values), so going off is going on played backwards. It always ends at the thumb's far edge, and its opacity follows the thumb's progress (1.6√p, with the last 3% counted as home). Going on, it fades in as it sweeps across. Going off, it stays solid most of the way and reaches zero exactly as the thumb arrives, so no ring is left. Never use timers that let the colour and the thumb drift apart. No shadows. | Switch |
| An icon that represents a state (copy → copied, sun → moon) | Swap through Loading Button's blur + rise, with a check that draws in, or morph on `spring.snappy`; `initial={false}` either way. A bigger moment can morph one drawing (Theme Toggle's `SunMoon`: masks and transforms only). | Copy Button (the site uses it for every copy action), Theme Toggle |
| Hover and press on a button | **No scale, glow or shadow** (owner, 2026-10-14). One tint layer (`::before`, `bg-current`) behind the label. It fades to 10% while rising 4px from the bottom on hover, and deepens to 15% on press. Links fade their underline in instead. `cursor-pointer`. | Button |
| Hover (other elements) | Colour and background transitions only (`duration-(--duration-fast) ease-out`) | everywhere |
| A validation message | It follows the value. It shows while the rule is broken and goes as soon as it's met, gliding open and shut through the blur (opacity, blur and height, `duration.base`, `ease.out`) inside a polite live region. The field's border colour fades with it. | Input's Invalid demo |
| Long list in a popup | No scroll arrows: the list scrolls natively (capped at 18rem), with soft fades at the edges that can scroll. The selected option opens centred. Add search for long lists (Select's `searchable`). | Select |
| Items appearing in a list or grid | Rise 12px through the blur, staggered by 0.05s (`duration.slow`, `ease.out`) | `Expandable` |
| Async action on a button | Loading Button: the content swaps through the blur with a 6px rise (`swap`: the old lifts away blurring, the new rises in from blurred) at a fixed width sized to the widest state. Spinner while loading; a check or cross draws in; solid destructive colour on error; back to idle after 2s. No shake. | Loading Button, Copy Button |
| The result of checking a code (OTP) | **Wrong:** the field shakes its head once (`x` 0, −8, 7, −5, 3, −1, 0px, `duration.slower`, `ease.out`) as its borders turn destructive; the owner's one exception to "no wiggles" (2026-10-21). **Right:** a wave left to right, each box swelling 6% and settling (`duration.slow`, `ease.out`, 0.05s apart) as its border turns solid `primary`. Colour only with reduced motion. | Input OTP (`status`) |
| A number that changes (counts, prices, steps) | It rolls like an odometer: each digit is a column that slides to its new digit (transform), rising as it grows and falling as it shrinks. Number Ticker: its engine, its 900ms `linear()` spring and 450ms fades (the `flow` preset), continuous counting, characters gliding and fading at a masked edge (`--size-roll-fade`); each digit a column placed by CSS mod() from one animated number; see its decisions.md. Number Input's steps roll a whole line with places staggered from the right. Never a tween through every number. Tabular figures, so the width holds. Screen readers get the final value only. | Number Ticker, Number Input (steps), Textarea's counter |
| A value that keeps updating (progress) | It rises continuously, not in parts: each change lasts as long as the gap since the last, at an even pace, while the updates keep coming (under 1s apart), so the fill never stops to wait; a change after a pause eases in (`duration.slow`, `ease.out`). The percentage counts through every number in step with the fill, the owner's exception to "never a tween through every number" (2026-10-21). Never a spring. | Progress (`useFollow`) |
| Dragging past a limit (a slider's ends) | The limit gives like elastic: the track stretches towards the pointer from its far end, resisting harder the further it goes (never past 16px), slimming a little, the end's thumb riding the tip; released, it snaps back on `spring.bouncy`. Transforms only; off with reduced motion. | Slider |
| Rows that change order (sorting) | FLIP: put each moved row back where it was drawn with `translateY` and spring it to 0 on `spring.snappy`. Offsets, not on-screen boxes; rows stay real `tr`s. Only a change of order moves. | Table |
| A step forward in a sequence | Progress travels: the step left behind swaps its number for a drawn check, the line between fills (`scaleX` / `scaleY`, eased tween), and the next step's ring grows in as the fill arrives. Going back plays it backwards. | Stepper |
| Hints over a row of controls (toolbar) | The first tooltip waits and animates in. Moving along the row, the next ones appear at once with no animation, and the previous one goes in the same frame. | Tooltip, Hover Card |
| A loop that runs on its own (marquee, sheen, drift) | A Web Animations transform loop, paused off-screen and in a hidden tab, still with reduced motion. Pausing (hover, focus) eases the speed to 0 instead of freezing: pause the loop and step its `currentTime` by hand at the easing speed, then play it again from there. Never ease `playbackRate` every frame: on a compositor animation the clocks drift and it snaps on release (Marquee, 2026-10-21). Several on a page stay in step (`startTime = 0`). | Marquee, Skeleton, Text Shimmer, Backgrounds |
| A panel that changes size between sections (mega menu) | The shared panel's width and height glide to the new content (`duration.base`, `ease.out`) while the content slides 12px in from the side moved towards, through the blur. | Navigation Menu |
| Theme change | Theme Toggle / `revealTheme()` (View Transitions) | Theme Toggle |

## Pitfalls already hit
- A gliding indicator painted over the rows it passes: make the container `isolate`, and don't give the rows their own stacking context (Select, 2026-10-13).
- `layoutId` breaks inside scroll containers. Use `RowIndicator`, or `layoutScroll` on the scroller.
- Transforms on SVG: a CSS transform replaces the `transform` attribute. Wrap the element in a `<g transform>` and animate the inner element.
- Masks and ids: every instance needs its own id (`useId()`), because pages render many copies.
- `layout` animations measure on-screen boxes, so they double their movement inside CSS `zoom` or a scaled parent (the zoomed Switch preview overshot its track). For controls, place them with numbers instead (`x`, width).
- `MotionValue.set()` right before a spring counts the jump as speed, so the spring overshoots (Radio Group's first slide, 2026-10-15). Place a value with `jump()`, which resets the speed, before animating it.
- A spring at a screen edge overshoots past it (`spring.snappy` by about 1%), briefly opening a gap. Extend the panel past its edge (Sheet: 8px, with a border in its own colour) so the overshoot shows more panel, not a gap (2026-10-16).
- `AnimatePresence initial={false}` blocks the entrance of **every** motion element under a child that was there at first, for good: a highlight mounting inside it later pops in instead of fading. Reset it inside the child with `<PresenceContext.Provider value={null}>` (Breadcrumb's levels, 2026-10-19).
- `AnimatePresence` needs keyed children, and unkeyed static siblings all get the same empty key. Pass `Children.toArray(children)`, which keys them by position (and unwraps lazy children from server components).
- Overlays that depend on scroll position (fades) go outside the scroll container, and the list's end is measured from its last shown child. A gliding highlight and in-list overlays inflate `scrollHeight`.
