# 0015 · CI on GitHub Actions

- **Status:** Accepted (2026-10-23, owner: "start with CI")
- **Builds on:** the plan's §8 quality bar; `pnpm check` (AGENTS.md)

## Context
The repo is public, MIT licensed and pushed to `main` often, and other people install from it (the registry, the Smooth UI skill). Until now nothing checked a push: `pnpm check` ran only when someone remembered.

## Decision
- **`.github/workflows/ci.yml`** runs on every push to `main` and every pull request, in two jobs side by side:
  - **Lint, types, tokens and tests:** `pnpm check`, the same command as locally (Biome, the item index's freshness, the typecheck, the design-token check and every component's Vitest + axe tests).
  - **Build the site:** `pnpm build`, which also builds the item index, the registry, the skill zips, llms.txt and every page's Markdown, so a guide with a block the Markdown can't write out fails here.
- **Setup:** Ubuntu, Node 24 (the site's engine), pnpm from `packageManager` (`pnpm/action-setup` reads it), the pnpm store cached by `actions/setup-node`, `pnpm install --frozen-lockfile`. Read-only permissions; a newer push cancels the run it replaces.
- **No remote cache and no secrets.** Deploys stay manual from this machine (ADR 0005); CI never deploys.
- **`turbo.json`** build outputs now leave out `.next/dev/**` (Turborepo's own guide) and include `public/skills/**`, so a cache hit restores the skill zips along with the registry.

## Consequences
- A broken push shows a red cross on GitHub and in the commit list; nothing blocks it yet. Making the checks required for `main` is a repository setting (branch protection) the owner can turn on.
- Not built yet: the plan's later CI steps (`shadcn registry validate`, a smoke test that installs a component into a fresh Next app, visual snapshots in light and dark).
- The first run found nothing new. Writing it caught a formatting slip in `turbo.json` and the build's "Failed to load dynamic font for ⌘" warning: Geist has no ⌘, so Command's social card lost the symbol. Social cards now spell it "Cmd+" (`components/og-card.tsx`).
