# Marquee: decisions

**Status:** published directly, without a Lab step (2026-10-16, built from the roadmap note "A row of logos or cards that scrolls on its own"). Category Effects. The page opens on "Logos and cards": a row of wordmarks travelling left and a row of quote Cards travelling right, named underneath, with a Pause switch at the top right. The one example is Vertical (two columns, up and down). The index card shows one row of wordmarks (`preview.card`).

- **What it is:** a band of items that moves on its own, round and round. Not a shadcn component; the API: `direction` (`left | right | up | down`), `speed` (px/s, 40), `pauseOnHover` (true), `paused` (false), `gap` (a CSS length or pixels; `gap-4` when left out), `fade` (true). Items go straight inside.
- **Seamless loop:**
  - The children are repeated until they cover the row with one copy to spare (at least two), measured on mount and whenever the row or a copy resizes (ResizeObserver). The track slides exactly one copy and its gap (the distance between the first two copies' offsets), then starts over, which looks the same. The server renders two copies; the browser adds what the width needs.
  - **No `repeat` prop:** the count is always worked out, so it can't be too few on a wide screen or wasteful on a narrow one.
  - **Rebuilt in place:** a resize or a new speed rebuilds the loop from the same phase, so it never jumps back to the start.
- **Cost:** one Web Animation on the track's `transform`, linear and infinite, so the compositor runs it without React or the main thread. No CSS keyframes are shipped (the brief). It's paused off-screen (IntersectionObserver) and while the tab is hidden (`visibilitychange`), and cancelled on unmount.
- **The crafted part: it slows to a stop rather than freezing.** Hover (mouse only, with `pauseOnHover`), keyboard focus inside, and `paused` glide the loop's speed to 0 over `duration.slow` on `ease.out` (motion's `animate` driving the rate), and back to full when released, on from exactly where it stopped. **How (revised 2026-10-21):** the loop runs by itself only at full speed. While the speed glides, the loop is paused and its `currentTime` stepped by hand each frame at the gliding speed, then it plays again from there. It used to glide `playbackRate` itself, and changing that every frame on an animation the compositor runs let the two clocks drift: the owner saw it shift on hover, then snap on leaving to where it would have been without the hover. A freeze reads as a glitch; slowing reads as the band making room for you. Mounting with `paused` starts at rate 0, without a glide.
- **Accessibility:**
  - **Each item once:** the copies after the first are `aria-hidden` and `inert`, so screen readers read the items once and Tab never lands on a copy's link.
  - **A way to stop it (WCAG 2.2.2):** moving content that lasts more than five seconds next to other content needs a pause control. `paused` is that hook; the hero wires it to a Switch. Focus inside also stops it, so a keyboard user can read and press a link.
  - **Reduced motion:** it doesn't move. One copy, in a row you can scroll (`overflow-x-auto`, or `-y-` when vertical), with no fade, focusable (`tabIndex=0`, the focus ring) so the keyboard can scroll it. This switches after hydration, so the server's HTML (the moving row) is what hydrates.
- **Look:** the ends fade through a static mask (a linear gradient over the row's first and last 10%), so items arrive and leave softly on any surface. A mask rather than overlay gradients in `background`, because overlays assume the marquee sits on `bg-background` (it often sits on a card or a preview tile). Painted once; only the track moves under it.
- **Right to left:** the copies run leftwards from the right edge, so the loop sits one copy further right; the distance is measured with `Math.abs`.
- **Demos:** the hero's wordmarks are text in `text-muted-foreground`, each with its own weight and tracking, the way real logos differ (no images). They carry their own `px-6`, with `gap={0}`, so the spacing stays on the 4px grid. The quote cards are our Card as a `figure` (`blockquote`, `figcaption`); the row has `py-2` so their shadows aren't clipped by the marquee's `overflow-hidden`. The demo root is `w-full min-w-0`, so the long track can't widen the preview's grid.
- **Tests:** the copies fill the row (stubbed offsets and width) and are aria-hidden and inert, links met once; the loop's keyframes, duration from the speed, infinite and linear; right, up; slowing to a stop when paused (paused and stepped by hand, holding its time) and picking up from there without a jump; mounting paused; hover and focus; pauseOnHover off; resting off-screen and in a hidden tab; still and scrollable with reduced motion; cancelled on unmount; axe.
- **Not built yet:** a built-in pause button (use `paused`); dragging or flicking it; varying speed by viewport; RTL checked in a browser (the shift is reasoned, not seen).
