# Introduction

FewTone UI is a free, open-source set of accessible React components for Next.js. Every component is built with Tailwind CSS and Radix, and you own the code: it is copied into your project, not hidden in a package.

## How it works

FewTone UI follows the same model as shadcn/ui. You add a component with one command, and its source lands in your project, ready to change.

```bash
npx shadcn@latest add @fewtone/button
```

You can also copy the source by hand from any component page.

## What you get

- **Accessible by default.** Components use Radix for behaviour, support the keyboard, and show a clear focus ring.
- **Yours to customize.** Styles are plain Tailwind CSS classes and CSS variables, in light and dark mode.
- **Works with your stack.** React 19, Next.js and Tailwind CSS v4, installed with the shadcn CLI.
- **Free and open source.** MIT licence, for personal and commercial projects.
