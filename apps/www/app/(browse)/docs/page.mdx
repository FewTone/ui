# Introduction to FewTone UI

FewTone UI is a free, open-source collection of accessible React components for Next.js, built with Tailwind CSS v4 and Radix. You add a component with one shadcn CLI command, and its full source lands in your project, ready to read, change and ship.

## What is FewTone UI?

FewTone UI is a component library you copy, not one you depend on. Each component is a single, readable TypeScript file that lives in your codebase, next to your own components. There is no package to keep up to date and no styles to override: you change the code directly.

It works the same way as [shadcn/ui](https://ui.shadcn.com), and uses the same CLI and the same colour names. FewTone UI components sit naturally next to shadcn/ui ones and take your project's theme as they are.

## Why use FewTone UI?

- **Accessible by default.** Components are built on Radix primitives and follow the WAI-ARIA patterns. They work with a keyboard, show a clear focus ring, and are tested with axe for accessibility issues.
- **You own the code.** The source is copied into `components/ui`, so you can rename props, change styles or remove what you don't need.
- **Styled with Tailwind CSS v4.** Every style is a Tailwind class or a CSS variable, in light and dark mode.
- **Considered motion.** Select highlights glide and switches spring into place, using shared presets. Everything respects the operating system's reduced-motion setting.
- **Built for your AI assistant.** Every component page has a **Copy prompt** button: a step-by-step brief your assistant can follow to add the component without touching the rest of your app.
- **Free and open source.** MIT licence, for personal and commercial projects.

## How it works

1. **Pick a component** from [the components page](/components). Each one has a live preview, usage code, examples and its full API.
2. **Run its install command.** The shadcn CLI reads the component from the FewTone UI registry at `ui.fewtone.com`.
3. **The CLI writes the source into your project** and installs its npm dependencies. The first time, it also adds the FewTone UI tokens to your global CSS file: sizes, motion durations and the focus ring. It only adds variables you don't have yet, so your theme stays as it is.
4. **Import it and make it yours.**

```bash
npx shadcn@latest add https://ui.fewtone.com/r/button.json
```

```tsx
import { Button } from "@/components/ui/button"

export function Actions() {
  return <Button>Continue</Button>
}
```

The [installation guide](/docs/installation) covers every step, including installing by hand.

## Built with

- **[React 19](https://react.dev)** and **[Next.js](https://nextjs.org)** with the App Router
- **[Tailwind CSS v4](https://tailwindcss.com)** for styles, with CSS variables for the theme
- **[Radix UI](https://www.radix-ui.com)** for accessible behaviour: focus management, keyboard support and ARIA attributes
- **[Motion](https://motion.dev)** for the components that animate with JavaScript
- **[shadcn CLI](https://ui.shadcn.com/docs/cli)** to install components from the registry

## Accessibility

Accessibility isn't an extra. Every component:

- works with the keyboard alone, with the keys each WAI-ARIA pattern expects
- shows a visible focus ring for keyboard users
- has the right roles and ARIA attributes for screen readers, from Radix
- keeps animations short and turns them off when the system asks for reduced motion
- is tested with Testing Library and axe before it is published
