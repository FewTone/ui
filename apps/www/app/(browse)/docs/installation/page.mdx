# Installation

Add FewTone UI components to a Next.js project with one shadcn CLI command, or copy the source by hand. Either way, the code ends up in your project, and nothing else in your app changes.

## Requirements

| What | Version | Why |
| --- | --- | --- |
| React | 19 | Components use React 19 APIs |
| Tailwind CSS | v4 | Styles use Tailwind v4 syntax, such as `h-(--size-control-md)` |
| Next.js | App Router | What FewTone UI is built and tested with |
| shadcn CLI | latest | Installs components from the registry (`npx shadcn@latest`) |

Your global CSS file should import Tailwind with `@import "tailwindcss";`. If it uses `@tailwind base;` instead, the project is on Tailwind v3: [upgrade to v4](https://tailwindcss.com/docs/upgrade-guide) first.

## Install with the shadcn CLI

### 1. Create a Next.js app (new projects only)

Skip this step if you already have a Next.js project. Answer yes to Tailwind CSS and the App Router.

```bash
npx create-next-app@latest my-app
```

### 2. Set up shadcn

Run this once per project. It creates `components.json` (where your components and helpers go), the `cn` helper that every component imports, and your theme's CSS variables. If your project already uses shadcn/ui, skip it: never run `init` again on an existing project, as it rewrites your theme.

```bash
npx shadcn@latest init
```

### 3. Add a component

Copy the command from any component page, or from here. Pick your package manager: the choice is remembered across the site.

<InstallCommand name="button" />

### 4. Use it

The component is now in `components/ui`. Import it like any of your own components.

```tsx
import { Button } from "@/components/ui/button"

export function Actions() {
  return <Button>Continue</Button>
}
```

## What the CLI adds

Each component brings its source file and the npm packages it needs:

<InstallTable />

The first install also adds the **FewTone UI tokens** to your global CSS file: control and icon sizes, motion durations and easings, the focus ring, the popover layer, and the open and close animations. The CLI only adds the variables your project doesn't define yet, so your colours, fonts and radius stay exactly as they are.

Components that animate with JavaScript, such as Select and Switch, also add `lib/motion.ts`: the spring presets they share.

Running the same command again is safe. If the CLI asks to overwrite a file you've changed, answer no to keep your edits.

## Install several components at once

Pass several addresses to one command:

```bash
npx shadcn@latest add https://ui.fewtone.com/r/button.json https://ui.fewtone.com/r/select.json
```

## Shorter commands with the @fewtone namespace

To write `@fewtone/button` instead of the full address, add the FewTone UI registry to `components.json`:

```json
{
  "registries": {
    "@fewtone": "https://ui.fewtone.com/r/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @fewtone/button @fewtone/select
```

## Install manually

You can also install without the CLI. Every component page has an **Installation** section with the steps in order:

1. install the npm dependencies
2. add the FewTone UI tokens to your global CSS file (only the variables you don't have)
3. add `lib/motion.ts`, if the component animates with JavaScript
4. copy the component's source into `components/ui`
5. update the import paths to match your project

If your project has no `cn` helper, add one at `lib/utils.ts`:

```ts
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

## Customize the theme

FewTone UI components take their colours, corners and fonts from CSS variables, so they follow your theme in light and dark mode without any changes.

**Colours.** Components use the same semantic names as shadcn/ui: `background`, `foreground`, `primary`, `secondary`, `muted`, `accent`, `border`, `input` and `ring`. Change them and every component follows.

```css
:root {
  --primary: oklch(0.17 0 0);
  --primary-foreground: oklch(1 0 0);
}

.dark {
  --primary: oklch(0.97 0 0);
  --primary-foreground: oklch(0.13 0 0);
}
```

**Dark mode.** Dark values apply under the `dark` class on the `html` element, which is how [next-themes](https://github.com/pacocoursey/next-themes) works.

**Radius.** Corners come from `--radius`. Set it once to make every component rounder or sharper.

**Sizes and motion.** The FewTone UI tokens tune every component at once:

```css
:root {
  --size-control-md: 2.25rem; /* height of buttons, inputs and selects */
  --duration-fast: 150ms; /* hover and press transitions */
  --scale-press: 0.97; /* how far buttons sink when pressed */
}
```

When the operating system asks for reduced motion, the durations drop to almost nothing and spring animations become instant.

## Troubleshooting

**The CLI says `components.json` was not found.** Run `npx shadcn@latest init` once in the project, then add the component again.

**Components render without styles.** The project is probably on Tailwind CSS v3. FewTone UI needs v4: check that your global CSS file has `@import "tailwindcss";`.

**`Cannot find module '@/lib/utils'`.** Your import alias or utils path is different. Check the `aliases` in `components.json` and `paths` in `tsconfig.json`, or add the `cn` helper shown above.

**A file already exists.** The CLI asks before overwriting. Answer no to keep your version.

**Animations don't play.** Check whether reduced motion is turned on in your operating system's accessibility settings. FewTone UI turns animations off when it is.
