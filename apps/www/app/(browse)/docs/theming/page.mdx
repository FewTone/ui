# Theming

FewTone UI components take their colours, radius and fonts from CSS variables. Change the variables and every component follows, in light and dark mode.

## Colours

Components use semantic names such as `background`, `foreground`, `primary`, `muted` and `border`. They are the same names shadcn/ui uses, so FewTone UI components take your project's colours and sit naturally next to shadcn ones. Change them and every component follows.

```css
:root {
  --background: oklch(1 0 0);
  --foreground: oklch(0.17 0 0);
  --primary: oklch(0.17 0 0);
  --primary-foreground: oklch(1 0 0);
}

.dark {
  --background: oklch(0.13 0 0);
  --foreground: oklch(0.97 0 0);
}
```

## Dark mode

Dark mode follows the `dark` class on the `html` element, which is how `next-themes` works. Set different values for each variable under `.dark`.

## Radius

Corners come from `--radius`. Set it once to make every component rounder or sharper.

```css
:root {
  --radius: 0.625rem;
}
```

## Fonts

Components inherit the page font. Set `--font-sans` and `--font-mono` to use your own.

## Sizes and motion

The FewTone UI tokens, added to your CSS on the first install, set the rest. Change them to tune every component at once.

```css
:root {
  --size-control-md: 2.25rem; /* default height of buttons, inputs and selects */
  --duration-fast: 150ms;     /* hover and press transitions */
  --scale-press: 0.97;        /* how far buttons sink when pressed */
}
```

With reduced motion turned on in the operating system, the durations drop to almost nothing and the spring animations become instant.
